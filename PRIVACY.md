# Privacy Policy

**Last updated:** May 2026

Weavestream is open-source, self-hosted software. We do not operate a hosted service, and we never have access to your data.

## The Software

When you run Weavestream, it operates entirely within your own infrastructure. Weavestream does not:

- Transmit any data to Weavestream developers or third parties
- Include telemetry, analytics, or usage tracking of any kind
- Phone home for license validation, update checks, or any other purpose

Your data stays on your servers. Full stop.

## This Website (weavestream.io)

This website is a static site with no tracking scripts, cookies, or analytics. We do not collect any information about visitors.

## GitHub

The Weavestream project is hosted on GitHub at [https://github.com/Weavestream/Weavestream](https://github.com/Weavestream/Weavestream). If you open an issue, submit a pull request, or otherwise interact with our GitHub repositories, that activity is governed by [GitHub's Privacy Policy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Contact

If you have any privacy-related questions, please open an issue on [GitHub](https://github.com/Weavestream/Weavestream/issues).
